## Agent skills
- Before planning or writing code, check .agents/skills/ and read every skill that applies to the task.
- Follow those skills' guidance over general habits. If a skill conflicts with this file, this file wins.
- In every plan, list which skills you used and how they shaped the plan.
- Install new skills only from official vendor or maintainer repos with `npx skills add <owner/repo> --skill <name>`, and keep skills-lock.json committed. Never install skills from local or temp paths.
